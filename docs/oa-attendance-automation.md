# 泛微OA考勤自动化系统

## 概述

本系统用于自动从泛微OA下载考勤数据，并分析旷工记录，后续可自动提交请假申请。

---

## 系统信息

| 项目 | 内容 |
|------|------|
| OA地址 | http://112.16.178.98:8088/ |
| 登录方式 | 工号 + 密码 |
| 考勤文件位置 | 通知公告 → 考勤标签 → 最新考勤数据 → 下载 |
| 请假申请位置 | 我的门户 → 我的流程 → 新建流程 → 人事流程 → XL-请假申请流程 |

## 使用方法

### 方法一：命令行手动执行

#### 1. 下载考勤数据

```bash
node scripts/oa-attendance-sync.js
```

**执行流程：**
1. 启动无头浏览器
2. 登录泛微OA (http://112.16.178.98:8088/)
3. 点击通知公告区域的"考勤"标签
4. 点击最新的考勤数据链接
5. 点击"下载"按钮
6. 保存到 `data/oa-export/` 目录

**输出文件命名规则：**
- 原始文件名：`202606考勤汇总（06.15-06.21）.xlsx`
- 重命名后：`attendance-202606.xlsx`

#### 2. 分析考勤数据

```bash
# 仅分析，不提交请假
node scripts/oa-leave-request.js --dry-run

# 分析并提交请假（待完善）
node scripts/oa-leave-request.js
```

**执行流程：**
1. 读取最新的考勤Excel文件
2. 从文件名提取日期范围（如 `2026.6.15-2026.6.21`）
3. 筛选目标员工（潘夏煜）在日期范围内的记录
4. 只分析"旷工"列有数据的记录
5. 输出旷工日期和时长

**输出示例：**
```
目标日期范围: 2026-06-15 ~ 2026-06-21
找到 7 条 潘夏煜 的考勤记录
2026-06-15: 旷工 1小时 (60分钟)
2026-06-16: 旷工 1.5小时 (90分钟)
2026-06-21: 旷工 2小时 (120分钟)

发现 3 条旷工记录
  2026-06-15: 旷工 1小时
  2026-06-16: 旷工 1.5小时
  2026-06-21: 旷工 2小时
```

### 方法二：API接口

```bash
# 查看同步状态
curl http://localhost:3000/api/oa-sync/status

# 仅下载考勤
curl -X POST http://localhost:3000/api/oa-sync/download

# 仅分析（不提交请假）
curl -X POST http://localhost:3000/api/oa-sync/analyze

# 完整同步
curl -X POST http://localhost:3000/api/oa-sync/run
```

### 方法三：自动调度

系统会在以下时间自动执行：

| 时间 | 操作 |
|------|------|
| 每周二 20:00 | 下载考勤 + 分析缺勤（不提交请假） |
| 每周三 08:00 | 下载考勤 + 提交请假 |

## 考勤Excel文件结构

### 文件命名规则

```
{年月}考勤汇总（{开始月}.{开始日}-{结束月}.{结束日}）.xlsx
```

示例：`202606考勤汇总（06.15-06.21）.xlsx`

### 列结构

| 列索引 | 字段名 | 说明 |
|--------|--------|------|
| 0 | 所属单位 | 公司名称 |
| 1 | 部门 | 一级部门 |
| 2 | 子部门 | 二级部门 |
| 3 | 岗位 | 职位 |
| 4 | 姓名 | 员工姓名 |
| 5 | 日期 | Excel日期序列号 |
| 7 | 打卡记录 | 格式：`8:03进21:42出` |
| 14 | 应出勤 | 应出勤工时 |
| 16 | 请假 | 请假工时（负数） |
| 17 | 旷工 | 旷工工时（负数） |

### 日期范围提取

脚本会从文件名自动提取日期范围：
- 文件名：`202606考勤汇总（06.15-06.21）.xlsx`
- 提取年份：`2026`（从文件名前6位）
- 提取范围：`06.15-06.21`
- 最终范围：`2026-06-15 ~ 2026-06-21`

只处理该日期范围内的考勤记录，忽略其他日期。

## 常见问题

### Q1: 下载的考勤文件在哪里？

A: 在 `data/oa-export/` 目录下，文件名格式为 `attendance-{年月}.xlsx`

### Q2: 如何只分析特定日期范围？

A: 脚本会自动从文件名提取日期范围，如 `202606考勤汇总（06.15-06.21）.xlsx` 只分析6月15日至6月21日的数据

### Q3: 如何修改目标员工？

A: 编辑 `scripts/oa-leave-request.js`，修改 `targetEmployee` 字段

### Q4: 如何修改工作时间？

A: 编辑 `scripts/oa-leave-request.js`，修改 `workSchedule` 配置

### Q5: 为什么5月31日的数据不处理？

A: 因为考勤文件只覆盖指定日期范围（如6.15-6.21），范围外的数据会被自动过滤
